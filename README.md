# preval-aeon-eval

Workspace for the aeon-preval dissertation work.

This repository is for exploratory and supporting work that should stay separate from the upstream-facing `aeon` fork, including:
- experiment scripts
- intermediate analyses
- dataset notes and small metadata files
- notebooks
- dissertation support material

## Layout

- `scripts/`: experiment and utility scripts
- `data/`: local dataset metadata, manifests, and small tracked assets
- `notebooks/`: exploratory notebooks
- `docs/`: notes, plans, and writeups

## Notes

Large raw datasets and generated artefacts should stay out of git unless there is a clear reason to version them.
